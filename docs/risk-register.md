- `CF-v2.19.5-F` — closed at v2.19.6 Phase 1/4 as **MISDIAGNOSED, not fixed** (`AC-PUB-8`). The
  original row claimed all five pre-existing releases (`v2.18.0`–`v2.19.3`) "fail permanently
  with no remedy path" because the post-condition rejected any body without the dotted version
  string. Re-diagnosed live 2026-08-07 by reading all five bodies through `gh release view`:
  every one of them **does** name its version, in the house anchor form
  (`CHANGELOG.md#<dots-stripped>---`) GitHub's slugifier produces from this repo's own
  `## [x.y.z] - date` headers — the bodies were never broken. `v2.19.1`'s single dotted-form hit
  was an accidental pass, traced to an unrelated editorial-provenance sentence added at
  v2.19.2, not evidence the old predicate worked. The other four were never broken either. The
  prescribed fix — widen the `gh release edit` repair branch to fire on "missing version
  string" — would have overwritten four curated, irreplaceable editorial bodies (as little as
  652 bytes each) with raw multi-kilobyte CHANGELOG excerpts, destroying content to repair
  nothing. **Actual fix:** the predicate itself was too narrow (dotted-only); widened to accept
  the anchor form too, in one shared definition (`scripts/release-predicate.sh`) — see
  `docs/architecture.md` ADR-077 §D1/§D2.
